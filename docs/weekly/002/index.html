雨落·立秋

八月第二周：围绕转正答辩、健康与投资做一次回望，也验证了“一次只做一件最重要的事”在自己身上有效。

慢慢地过完了八月份的第二周。

本周总体的感受，是秋意开始慢慢到来，毕竟已经过了立秋。周一开头和周五结束时的两场暴雨，让整个北京慢慢变得凉爽起来，虽然下周可能也会有更多的雨。

今天重点不是要规划这周该干什么，而是总结一下上周做了什么，以及上周的一些思考。

一周回望

1. 工作与转正

上周一直在忙转正的事情，整个一周的忙碌好像都在围绕写文档、准备转正答辩。关于工作上的思考其实比较平淡，没有特别多的东西。

2. 生活与健康

  • 运动： 上周好像没有怎么运动。
  • 减肥： 有两天吃了晚饭，不过最低体重达到了 136 斤，希望下周能再低一斤。

3. 个人项目与投资

  • 播客： 好像没有什么太大的起色。
  • 投资： 上周收益率还可以，总体加起来有点超乎预期，希望下周能够保持这样的收益。

4. 学习与日常规律

这周的文章好像没有怎么看，日常的规律也没有怎么形成。

除此之外，上周也进行了一些零碎的思考。虽然这些思考可能没有什么太大的用处，也不知道未来会在哪一点起作用，但至少算是一些阶段性的记录吧。

一些 flomo 笔记

一、主线与优先级：从提问到验证

周三（8/5）问自己：

如果今天或这周只能被人记住一个主线，或者只能做一个主线，这个主线是什么？

周五（8/7）早上写：

这周比较明显的一个感悟是一次只做一个最重要的事情……把优先级拿到之后再分配时间，而不是先来先服务。效率有明显的提升，而且会有一些松弛的时间，确实会更良性一点。

三天，从提问到实践结论——这条线是上周最完整的：我验证了“一件最重要的事”这个方法在自己身上有效。

二、理想作息与允许差错

第一条描了一整天的理想状态：六点半起床、看或写技术文章、运动、上午干最难的事、下午处理杂活加摸鱼、下班前复盘，晚上写播客、看书、写感悟、看投资。

第二条紧接着，是给自己的提醒：

这种作息如果被打乱……要允许出现一些差错。而不是出现一点问题之后就换一种方式，或者一直追求这个状态，没有给自己一点 buffer 的空间。

一边在画理想，一边也在防止自己“理想破碎就全盘推翻”——这两条放在一起，是对自己挺了解的一次。

三、答辩复盘

来高德五个月的总结：学到了一些工作方式，也打开了眼界。印象最深的是大仓模式的转变——从不解到理解：

如果纯靠数据做，有了完整的数据和可控的流程做支撑，它要比人更稳定一点。因为它有充分的上下文数据以及判断逻辑，而人在很多时候只有自己的上下文。

不足也写了：处理问题的方式，想多跟 AI 尝试，也多参考业界方法。

四、对阿里文化的思考

对阿里的感受有点像大跃进时期的浮夸风，很少有踏下心来做事情修行的感觉，fomo 的情绪很严重，导致文档大于实践。

这条和 8/5 之前对环境的判断一脉相承，但用了一个更狠的比喻。

五、80 分原则

做一个合格的 80 分其实已经很难了。把追求 95 分、100 分的精力往后放，不如拿去开拓更多的事。

六、租房闭环

过去半年了，担心的事情没有发生……努力和付出是值得的，最终还是租到了比较满意的房子。
