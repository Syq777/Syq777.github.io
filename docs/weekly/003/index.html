昼暮·四季未满

顺利转正之后，重新思考时机与努力、工作的落脚点和产品工程师方向，也记录窗外昼暮与一些尚未回答的生活问题。

站在工位所在的楼层往外看，一张是白天，一张是黄昏。

拍下它们的时候，我想的是：会不会有机会把这里的一年四季都集齐？或者，自己能在这里待满一年四季吗？

转正之后

最近工作已经顺利转正了。之前担心的那些事情并没有发生，也没有因为卡名额受到影响。可能那段艰难的时间，已经过去了。

时机可能比自己的努力本身更重要。或者换句话说，转正这件事，也许在真正转正之前就已经大致决定好了。

所以，是不是可以回顾一下过往的经历，看看所谓的“人为决定”到底是不是真的存在？

找到工作的落脚点

换个角度看，转正之后，最近工作的主线也需要重新找到一个落脚点：找到一个能够说服自己、带来成就感的地方，从而愿意持续投入。

节奏非常重要。如果要排个顺序，节奏肯定在第一位，其次是持续投入，然后才是从中获得一些成长。

生活：几件没有结论的小事

除了工作之外，生活好像没有太大的波动，但有几件事值得继续观察：

  • 亲密关系： 可能需要重新思考和梳理一下，避免因为长时间恋爱，而忽略了对彼此真实需求的思考。
  • 减肥： 总说要减，但其实一直没有正儿八经地量化成果。确实需要好好锻炼一下了。
  • 羽毛球： 有点想报班，不过先让子弹飞一会儿。如果未来一个月，也就是国庆之前，能够保证打上大概 10 次羽毛球，再来考虑报班的事。

一些 flomo 笔记

一、职业方向的重新校准

开始之前要多培养产品工程师的能力，代码能力只占 30%，更重要的是把自己的痛点和大部分用户痛点结合起来……产品工程师 = 用研 + 产品 + 工程师 + 运营 + 数据 + 商业的综合体。—— 8/11

写代码最有挑战、最有价值的部分在于设计……有产品思维、有一些脏活累活，多维的锻炼才是未来更符合时代发展的前提。纯做开发的话，就是一个执行者，很容易干不成。—— 8/16

AI 时代代码壁垒越来越小，更需要把控的是如何把 Token 刚好花在解决用户问题上。—— 8/11

这段时间，我对职业方向的判断正在变化：从“做技术”转向“产品 + 技术”。8/11 还在给“产品工程师”补课，到了 8/16，已经明确对纯业务开发没有执念了。转正刚过，职业方向的天平开始慢慢往产品侧倾斜。

不过，怎么执行呢？“产品工程师”是一个结果，不是一条路径。

二、Agent 技术命题

如何在有限的上下文窗口里高效地组织信息，让概率模型发挥出最大的能力。这应该是最值得研究的命题。—— 8/12

这也和前一条连在了一起：当写代码的壁垒越来越低，如何定义问题、选择上下文和组织信息，可能反而变成了更重要的能力。

三、生活图景与它的“庸俗感”

未来想的路径是一个小的、属于自己的房子，短暂拥有 5–7 年……有个车，车是很有安全感的东西，属于自己密闭的空间。虽然现在已经有可以买车的钱了。—— 8/12

好像现在看起来比较庸俗的成长路径是买车、买房、结婚、生子、换更大的房子和更好的车。—— 8/17

8/12，我还在认真描绘想要的生活：房子、车，以及某种安全感；到了 8/17，又突然觉得这套路径有些“庸俗”。

这两条之间还有一个没有写完的追问：如果买车买房是庸俗的，那“不庸俗”的版本是什么？我还没有答案。

四、协作方法论

如果合作两周后，你不光要负责自己的事，脑子里的事还越来越多，实际就是在消耗你的管理带宽。一个好的合作对象应该产生一种效果：事情交给他以后，可以从自己的工作记忆中删除。—— 8/13

五、自我觉察

每天的夜宵应该是情绪化的进食，不属于饿。可能并不饿，只是情绪化的一件事，这种要避免一下。—— 8/11

六、问题观

除了答案之外，还有更多的问题到底是什么？我们要解决的问题是不是真的问题？是不是已经有解法了？对现状有没有提升？而不是总想着创新、总想颠覆一切。勇敢地去创造。—— 8/22

比起急着给自己一个结论，眼下更重要的，或许仍然是把问题看清楚，然后持续去做。至于能不能集齐这里的一年四季，先把接下来这一季过好。
