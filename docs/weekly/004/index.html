北京的海

八月最后一周，骑摩托去密云看了一次“海”，也在月底重新回望工作、周刊、阅读、投资、财务与健康。

这周其实过得比较平淡，没有什么特别的事情发生。

工作上，感觉自己正在慢慢找回对时间的掌控；生活上，运动和阅读也该一点点重新加回来了。许多问题好像已经复盘过很多次，到了八月底，比起继续寻找新的解释，可能更重要的是把一些想做的事真正做起来。

骑着摩托车去了一趟密云。

从山上望下去，密云水库被一层层山岭围在中间。水面一直铺到远处，蓝得很安静。那一刻的确有点像是在北京看海。

八月复盘

1. 工作与转正

八月初的主线基本都围绕转正展开，目前已经顺利通过，算是这个月最明确的一项结果。

转正之后，接下来可以单独写一次职场复盘：重新梳理未来半年的规划，想清楚自己到底想要什么、准备怎样达成，以及更长期的职业发展路径。通过转正解决的是“留下来”的问题，后面更需要回答的，是准备往哪里走。

2. 周刊与副业

周刊已经写到了第四期。能开始，并且继续更新下来，本身算是八月一个意外的收获。

写作过程中借助了一些 AI。现阶段还是先发在自己的博客和网页上，之后再慢慢考虑同步到微信。现在的内容确实有点想到哪里写到哪里，还没有形成一条特别稳定的主线，但也不必急着在开始的时候就把一切定义清楚。先写下去，可能比一开始就设计出完整的栏目更重要。

相比之下，副业在八月基本没有真正开始。也许是因为担心投入之后看不到效果，所以一直停留在准备和设想里。

九月需要沉下心来梳理一下。副业不能只等同于内容输出，它还需要自己的沉淀、思考和理解。比起同时铺开很多方向，更重要的是先找到一个具体的起点，完成一次真正的交付。

3. 阅读

最近在读俞军的《产品方法论》，书里对产品的思路和理解，打开了不少之前没有想过的维度。

现在还只是一个开始。先慢慢读下去，再看看其中哪些东西能真正进入自己的工作和判断里。

4. 投资

这个月的收益虽然没有七月多，但截至月底，整体仍然是正的。

接下来还是考虑慢慢把分散在不同地方的资金归拢起来，集中管理，减少投资对日常注意力的占用。现阶段可以允许自己分散一些精力去学习，但从更长的时间尺度看，投资最终应该变成一套不需要频繁关注的系统，再把主要精力放回工作和生活。

这个过程可能需要五到十年，不用急着一次完成。

5. 财务支出

八月的支出比预想中多了一点。

基本的开支边界还是需要保留，但相比把大量精力用在一点点压缩消费上，后续更值得关注的，可能还是怎样提升收入。节流有上限，提升自己的能力和收入，才有可能带来更大的空间。

6. 运动与健康

这个月在运动和健康上做得不太好，这一项仍然只是计划，还不能算成果。
